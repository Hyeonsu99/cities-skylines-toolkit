## 검증 방법과 제한

`python projects/korean-lowrise/house_core.py`는 삼각형 예산, LOD 비율, 창수, 20cm 후퇴, 조경 태그 제외를 검사한다. 키트 final은 기하·FBX·LOD 렌더와 이미지 리뷰로 검증한다. `gate.json`이 최종 상태의 권위다.

단일 주소 실측 복제가 아니므로 `photo_refs.json`을 만들지 않았다. 사진·타일 정량 비교는 NOT_APPLICABLE이며 사진 일치 PASS를 뜻하지 않는다. 유형 사진은 직접 검토하고 위 근거와 합성 선택을 구분했다.

텍스처 main 2048 / LOD1 2048 / LOD2 512, 각 BaseColor·ControlMask·MaskMap·Normal·Emissive 5종이다. 현 키트 `export_asset`은 LOD1 텍스처 크기 인자가 없고 main을 복사한다. 권장 LOD1 1024보다 크지만 키트 수정·별도 exporter 없이 현 API 범위에서 내보낸다. 키트 수정은 사용자 승인이 필요하므로 이번 범위에서 하지 않는다.

## M1.5 — 재질·생활·실루엣·시드 조합 (2026-11-18)

추가 근거는 기존 거리뷰 A2_000의 기와 눈썹처마·불투명 청록 차양·흰 미장 담·석재 문주·철 대문·주소판, A3의 흰 소형 타일과 장식 띠·가게 차양, A5_270의 적벽돌 줄눈·창대·방범창·노출 배관이다. 사진 원본이나 상호를 텍스처로 복사하지 않고 키트 painter로 합성했다. A3/A5 일대는 여러 재료가 혼재하며, 특정 촬영 한 장이 모든 마감을 입증한다고 보지 않는다.

### 재료와 생활 요소

- 외벽: 적벽돌 / 흰 모자이크+청회색 다이아몬드 띠 / 아이보리·연회색 미장 / 대형 포세린, 총 5칸. 전부 G 채널. 흰 미장 담은 별도 칸이며 벽돌 담은 seed 4·9에서만 등장한다.
- 기단은 짙은 석재 타일과 흙튀김 painter. 창 아래 빗물·실외기 아래 녹물은 작은 alpha 컷아웃 얼룩 면이다. 벽에는 grain/stains, 타일에는 joints, 오염에는 noise를 쓴다.
- 녹색 `roof`는 수평 옥상 바닥에만 있다. 슬래브 측면·파라펫 외부는 본체 마감, 두겁은 시멘트 회색이다. 셀프 검사에서 녹색 면의 수평성을 확인한다.
- 1층 방범창, 일부 70년대 시드의 2층 방범창, 벽걸이 실외기+앵글, 노란 가스관+계량기, 불투명 폴리카보네이트 차양, 주소판 17-8·우편함·문주 등.
- 옥상 소품 5종: 빨래건조대 / 평상 / 장독대 / 위성안테나 / 태양열 온수기. 시드가 하나를 고르며 물탱크와 파랑·주황 강판 옥탑도 조합한다.
- 기와 눈썹 처마, 난간 발코니(출입문 포함), 알루미늄 샷시 확장 발코니, 실제 ㄱ자 외곽·옥상, 1층 닫힌 셔터 2칸과 천 차양을 구현했다. 가상 간판은 DAON SHOP. 상점 영업·Mixed 등록은 모델만으로 검증하지 않는다.
- R=수평 방수 바닥, G=외벽·담장, B=차양·셔터. 강판 옥탑은 자체 파랑/주황색을 유지한다. `_Gls` 없음. 주소·간판·창·바닥은 비발광, 작은 문주·현관 등기구만 발광한다.

시대는 시각적 유형이며 실제 준공연도를 단정하지 않는다. 발코니·옥탑·온수기 등 후대 개수선도 포함한 현재 동네 상태를 합성한다. `seeded(era, seed)`는 안정적인 문자열 시드를 가진 stdlib Random을 사용한다. 폭·깊이(8.4/9.0/9.6m), 마감, 발코니, ㄱ자, 가게, 옥탑 색, 옥상 소품, 계단·탱크·담장을 재현 가능하게 선택한다. 12시드에는 12개 서로 다른 조합이 있다.

### 추정치·단순화

- ㄱ자 후면 절삭 2.6×2.6m, 발코니 돌출 0.95m/난간 0.92m, 옥탑 2.3×2.0×1.98m, 기와 처마 돌출 0.48m/높이차 약 0.31m # estimated.
- 흰 담 높이 1.15m, 석재 문주 1.73m, 작은 등 상단 1.88m, 방범창 봉 두께 약 0.024m # estimated.
- 실외기 0.96×0.36×0.63m, 계량기·차양·옥상 소품 치수와 배치 모두 사진 유형을 따른 추정 # estimated.
- main/LOD1 유리는 0.20m 후퇴한다. LOD2는 500개 예산 안에서 창을 외벽 가까이 펼치고 뒤판을 닫아 사선 틈을 막는다. 원거리 디테일·계단은 단순화하며 실제 실내/생활 시뮬레이션은 없다.
- 기와 곡률·골, 강판 골, 모자이크와 포세린 줄눈은 painter/normal 표현이다. 모든 기와 낱장을 독립 메시로 만든 정밀 재현은 아니다.
- 나무·식생·화분·화단 틀·흙면은 메시 금지. `work/subobjects.json`은 마지막 생성 에셋용, `work/subobjects_<asset>.json`에 각 대표의 동일 스키마 제안을 별도 보관한다.
- main 2048 / LOD1 2048 / LOD2 512, 각 5 PNG. LOD1 1024는 키트 API·승인 이슈로 여전히 미적용이다.
