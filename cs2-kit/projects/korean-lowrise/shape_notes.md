## M1 설계

특정 주소를 복제하지 않고 A형 단서들을 합성한 시제품이다. 녹색 방수 옥상, 붉은 벽돌, 옥탑, 물탱크, 실외기, 외부 철계단, 담장·대문을 가진다. 사진의 상호·로고는 사용하지 않는다. 옥상 설비 배치와 치수는 실측이 아니다.

- 몸체 9.6×9.2m, 층고 3.05m×2층, 담장·포장 포함 13.6×13.5m, 옥탑 상단 8.28m # estimated.
- lot 2×2 = 16×16m는 키트 8m 셀에 맞춘 후보다. 실제 CS2 저밀도 구역 성장·등록 지원은 사용자 확인 대기.
- 창 개구부 1.70×1.35m, 2분할 14개 창/28개 유리면. 유리 좌표는 외벽에서 0.20m 안쪽이다. 외벽은 개구부를 비워 제작하고 실제 창대·인방·프레임을 더했다 # estimated.
- 외벽 두께 0.24m, 창대 돌출 0.10m, 벽돌 줄눈 0.009m # estimated.
- 외부계단은 1→2층, 폭 1.17m, 17단, 단높이 약 0.179m/디딤 약 0.285m. 상부 참과 측면 문이 연결된다 # estimated.
- 파라펫 높이 0.62m, 옥탑 높이 2.18m, 물탱크 지름 1.32m/높이 1.10m # estimated.
- 담장 1.15m, 대문 1.45m, 현관 차양 1.80×0.98m # estimated.
- ControlMask: R=지붕·옥상 방수, G=벽·담장, B=현관 차양. M1에 셔터는 없으며 M2 가게형에서 B=셔터·차양으로 확장한다.
- `_Gls`를 만들지 않는다. 창·벽·바닥의 발광은 0, 작은 현관 등기구 0.16×0.13m 면만 발광한다. 게임 야간 검증은 별도다.
- 식생·화분·화단 틀·흙면 메시 없음. `work/subobjects.json`의 `kind=planter` 제안을 에셋 에디터에서 배치한다. 좌표는 export 후 피벗 이동을 적용한 Z-up m 기준이며 에디터 축 대응은 확인한다.

## 검증 방법과 제한

`python projects/korean-lowrise/house_core.py`는 삼각형 예산, LOD 비율, 창수, 20cm 후퇴, 조경 태그 제외를 검사한다. 키트 final은 기하·FBX·LOD 렌더와 이미지 리뷰로 검증한다. `gate.json`이 최종 상태의 권위다.

단일 주소 실측 복제가 아니므로 `photo_refs.json`을 만들지 않았다. 사진·타일 정량 비교는 NOT_APPLICABLE이며 사진 일치 PASS를 뜻하지 않는다. 유형 사진은 직접 검토하고 위 근거와 합성 선택을 구분했다.

텍스처 main 2048 / LOD1 2048 / LOD2 512, 각 BaseColor·ControlMask·MaskMap·Normal·Emissive 5종이다. 현 키트 `export_asset`은 LOD1 텍스처 크기 인자가 없고 main을 복사한다. 권장 LOD1 1024보다 크지만 키트 수정·별도 exporter 없이 현 API 범위에서 내보낸다. 키트 수정은 사용자 승인이 필요하므로 이번 범위에서 하지 않는다.

## 사용자 인게임 확인 → M2 진입 조건

가져올 때 반드시 `projects/korean-lowrise/output/KoreanHouseA01_L1_2x2` 폴더를 고른다. 프로젝트 상위 폴더를 고르지 않는다.

1. 저밀도 2×2 lot 등록·구역 성장, 도로 쪽 -Y 현관 방향, 보행·세대 입주.
2. 수백 채 반복 배치에서 실제 크기·프레임·메모리·LOD 전환과 먼 창 안정성.
3. 야간 창·작은 등기구·카메라 이동시 떨림, RGB 색 변주 범위.
4. 화분 서브오브젝트 배치와 게임 축, 담장·대문 통행 표현.
5. B형 점포주택의 Mixed 구역 가능 여부와 lot 2×3/3×3, uzacha 필로티 빌라 현행 호환.

M1 결과를 보고한 뒤 멈춘다. M2의 A형 4~6종+B형 4~6종은 사용자 인게임 승인 후 별도 디스패치로 진행한다.
