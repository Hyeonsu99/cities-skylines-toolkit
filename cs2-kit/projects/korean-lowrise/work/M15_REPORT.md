## 12시드 비교 시트와 반복감 판정

각 시트는 **현재 코어로 다시 생성한 12개**를 동일 카메라·2048 아틀라스로 나란히 배치한 것이다. 세 시트 모두 직접 열어 전 항목을 검토했다. 레이블은 seed 0~11, 크기, 마감, 발코니/평면, 가게·소품, main tris를 표시한다. 대표 80s01은 seed 1, 90s01은 seed 2이며 시트의 임시 출력 이름과 대표 이름을 혼동하지 않는다.

| 시대 | 파일 | 직접 본 판정 |
|---|---|---|
| 70s | `work/variety_70s.png` | **색만 바꾼 복제 수준은 벗어났고 반복감은 낮음~중간.** 기와 처마가 시대를 묶지만 미장/모자이크/벽돌, ㄱ자·샷시/난간/무발코니, 계단 유무·담장·옥상 소품이 눈에 띄게 다르다. 같은 옥탑 위치와 2층 비례는 반복된다. |
| 80s | `work/variety_80s.png` | **반복감 중간.** 벽돌 가족성이 강하고 셔터 가게·포세린 개수선·확장 발코니·ㄱ자가 차이를 만든다. 2열 창과 동일 대지 포장, 뒤쪽 옥탑은 공통 인상이 남는다. |
| 90s | `work/variety_90s.png` | **반복감 중간.** 모자이크 무늬 띠와 포세린/미장, 주거/가게·발코니·물탱크 유무가 구별된다. 넓은 평지붕과 같은 2층 골격 때문에 수백 채의 단일 시대 연속 배치에서는 반복이 여전히 보일 수 있다. |

즉 36개가 모두 다른 실루엣인 것은 아니다. 같은 시대의 질서를 유지하면서 합성한 12개 조합이며, 실제 게임 ControlMask 색 변주와 시대 혼합 배치의 최종 효과는 사용자 확인이 필요하다. 낮은 반복감이 실제 게임에서 검증됐다고 표시하지 않는다.

## 검증

- `python projects/korean-lowrise/house_core.py`: 3시대×12시드 재현성·각 12개 고유 조합·4종 이상 마감·5종 옥상 소품·main≤8000·LOD1<50%·LOD2(창 포함)≤500·녹색 면 수평·조경 태그 제외 검사 PASS.
- `variety.py`: 키트 check.py로 **36/36 기하 PASS, 오류·경고 0**, render.py 렌더 36/36 완료. 결과는 `work/variety_manifest.json`. 36개 중 main 최대 6072(Win 포함 6128), LOD2 최대 Win 포함 492. 이 36개 전부의 FBX·64뷰 final을 실행한 것은 아니다.
- 대표 3개+기존 A01: 키트 final 4개 PASS, 현재 낮 4방향 이미지 각각 직접 검토하고 review PASS 기록.
- `previews/m15_night_70s.png`, `m15_night_80s.png`, `m15_night_90s.png` 직접 검토: 문주·현관의 작은 등만 발광, 창·벽·차양·간판은 비발광. 이 근사 야간 렌더는 게임 야간 조명·깜박임 검증을 대신하지 않는다.
- 초기 LOD2 창·확장 발코니의 사선 틈은 먼 창의 평면화·뒤판으로 막고 final을 다시 실행했다. 이전 FAIL/INCOMPLETE는 완료 상태로 재사용하지 않았다.

- 기와 처마 돌출 0.48m·낙차 약 0.31m, 발코니 돌출 0.95m·난간 높이 0.92m, 옥탑 2.3×2.0×1.98m, 파라펫 0.62m # estimated.
- 담장 1.15m·문주 1.73m·등 상단 1.88m, 계단 폭 1.17m·17단, 실외기 0.96×0.36×0.63m, 배관·계량기·소품 크기와 위치·오염 세기 모두 추정.
- 실내·상점 영업·건조대/온수기 작동은 미구현: 이 작업은 건물 시각 에셋이다. 기와 개별 곡률·강판 골·타일 줄눈은 painter/normal 중심으로 가볍게 표현했다.
- LOD1 1024는 **미적용**: 현재 export_asset에는 LOD1 크기 인자가 없고 main을 복사하며, 공용 키트 수정은 사용자 미승인이다. main 2048은 유지했다.
- 나무·화초·화분·화단 틀·흙면 메시 없음. `work/subobjects.json`은 마지막 생성 A01, 각 대표의 `work/subobjects_<asset>.json`은 위치·회전·scale·종류 제안이다. 실제 에디터 소품 배치와 축은 미검증이다.
- 비례·재료·오염은 유형 추정이며 특정 주소와 사진 정량 일치로 검증한 실측 모델이 아니다. 자세한 수치는 각 building_spec YAML과 shape_notes.md에 기록했다.
