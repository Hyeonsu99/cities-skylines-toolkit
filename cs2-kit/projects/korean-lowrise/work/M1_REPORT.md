## 한계·남은 문제

- D는 대전 현장 사진이 충분히 확보되지 않아 국내 타 지역 공개 사진 6장으로 보완했다. 실제 평촌·목상 분포와 지붕 재료는 M3 전 확인한다. 같은 건물의 여러 시점이 있어 24개 독립 건물 표본은 아니다.
- 현 키트 `export_asset`은 LOD1 크기 인자가 없어 main 2048을 복사한다. 권장 1024보다 크며, 키트 수정 없이 API 범위 내 main 2048/LOD2 512를 적용했다. 승인 없는 키트 변경은 하지 않았다.
- 식생·화분·화단 틀·흙면 메시 없음. 화분은 `work/subobjects.json`에 `kind=planter`로 위치·scale·회전·종류를 제안했다. 실제 에디터 소품 배치·축·크기는 검증하지 않았다.
- M1 코어는 평지붕 A형 주택만 구현. 가게 `feature_shopfront`, 박공/모임·필로티·다락은 M2에서 추가한다. 현재 지원하는 축은 lot·층수·벽색·옥상색·외부계단·물탱크·담장이다.
- 실제 상호·로고·사진 텍스처 사용 없음. 저작권 사진·큐브맵·생성 output/previews는 커밋에서 제외한다. 공용 키트와 병행 작업 프로젝트는 수정하지 않았다.

## 사용자 인게임 확인

가져오기는 반드시 `cs2-kit/projects/korean-lowrise/output/KoreanHouseA01_L1_2x2` 폴더를 선택한다.

1. 저밀도 2×2 등록·구역 성장·세대 입주·보행 연결과 전면 방향.
2. 수백 채 배치 시 크기·프레임·메모리, LOD 전환과 먼 창 떨림.
3. 야간 실제 창 표현·작은 현관 등·카메라 이동·RGB 색 변주.
4. 담장·대문 통행 표현, 에셋 에디터 화분 서브오브젝트 좌표·축.
5. B형 점포주택의 Mixed 구역 지원·2×3/3×3 lot, uzacha 필로티 빌라 호환 여부.

이 확인 뒤 사용자가 M2 진행을 승인하면 다음 디스패치에서 이어간다. 푸시는 별도 사용자 승인 필요.

## 재실행

키트 루트에서:

```powershell
python projects/korean-lowrise/house_core.py
python tools/agent.py cycle --project korean-lowrise --generator korean_lowrise_cs2.py --mode final --label m1-final --json
```

생성 후 반환된 아티팩트를 열고 `agent.py review`의 반환 명령으로 현재 이미지 리뷰를 기록한다. `research_photos.py`는 로컬 사진 재수집용이며 네트워크·사진 서비스 상태에 따라 결과가 달라질 수 있다.
