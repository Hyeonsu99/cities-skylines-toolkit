   - 동북 코너 솔리드 계단실 타워(`X = 20.5..24.8`) 전층 연속 수직 슬릿창 2열(북면 `Y = 69.2, X = 21.0..21.95, Z = 1.55..16.95 m` 1x11 격자; 동면 `X = 24.8, Y = 66.1..67.4, Z = 3.80..17.65 m` 2x9 격자) + 후퇴 커튼월 로비(`Y = 65.4`) + 남측 1층 `Y = 50.4..58.6` 구간 `X = 22.0` 필로티 후퇴 및 기둥(`Y = 51.4`)·하부 솔리드(`Y >= 58.6`).
   - 3층 체육관부 짙은 브라운 패널 + 3개 수평 띠창 + 상단 4단 수평 그루브 백색 파시아(북측면 유지), 옥상 필로티형 `나루마당`(`Z = 14.80..18.55 m`)에 백색 사각 기둥 2개소·낮은 북측 루버·평탄 두꺼운 백색 캔틸레버 지붕 슬래브(`X = -27.0..+27.0, Y = 49.6..71.4, Z = 18.55..20.00 m` — 벽 밖 서 2.5 m·동 2.2 m·북 체육관벽 3.0 m/타워 2.2 m 돌출 및 하부 `"roof_soffit"` 음영 면) + 파라펫(`20.32 m`) 내 저프로파일 태양광 어레이(`X_max=23.6`, 옥탑 박스 `21.15 m`) 배치. LOD1/LOD2 실루엣에도 동일 돌출·soffit 반영.
3. **중앙 중정 · 서측 그린테라스 · 동측 연결동 (`build_middle_courtyard_and_east`, `Y = 35.2..50.4`)**
   - 중앙 4면 유리 아트리움 오픈 중정(`X = -6.0..+8.2`, `14.2 x 15.2 m`) 및 북서 1층 연결 브리지 상부 녹지 화단.
   - 서측 2~3층 `그린테라스` 데크 위 `#`자형 백색 대형 퍼골라 캐노피(`X = -20.0..-9.4, Y = 37.4..47.8`)·조경 화단·유리 난간.
   - 동측 연결동은 1층 `X = 22.0` 후퇴 회랑 및 백색 기둥(`Y = 40.2, 45.6, 51.4`), 2~3층 백색 외벽 + 창호, 2층 데크(`Y = 35.2..51.8, X = 24.8..27.0, Z = 4.05..4.75`)와 `0.32 m` 흰색 솔리드 측벽(`X = 26.68..27.00`)으로 막힌 3단·2참 외부 대계단(`Y = 51.8..66.1, Z = 4.75->1.34`, `Y <= 58.6` 하부 필로티 오픈 소핏/안전펜스 + `Y >= 58.6` 바닥 접지 솔리드 몸체, `"terrace_deck"` 화강석 디딤판/챌판 + 3단 파이프 난간) + 북동 하부 테라스(`Z = 1.34`, U형 루프 레일 2개소) 및 8단 넓은 조경 계단(`X = 20.55..26.68, Y = 69.72..71.40, Z = 1.34->0.14`, 서측 옹벽 측벽 `X = 20.25..20.55`)·옥상 공조 설비 2군 구성.
4. **남측 2~3층 연속 커튼월 · 남서/남동 통합 백색 지붕 파시아 (`build_south_wings`, `Y = 9.65..35.2`)**

   - 8단 흰색 수평 차양 루버 핀은 주요 단(`Z = 6.12, 8.27, 10.42, 12.57 m`) 두께 `0.150 m` · 돌출 `0.50 m`, 사이 단 두께 `0.108 m` · 돌출 `0.40 m`로 서측 시작점을 `_ramp_x_at_zt(zb + half_t)`(경사로 윗면 교차점, `k=1..3` 약 `11.12 / 0.44 / -10.67 m`)까지 연장해 경사로 윗면에 밀착하고, 동측은 `Y = 35.2` 연결동 남측 벽면까지 연속 래핑(LOD1에도 반영). 상단 두께 `1.65 m` 통합 백색 캔틸레버 지붕 파시아(`Z = 14.80..16.45 m, Y = 9.65..10.75`, `석봉복합문화센터` 간판) 및 동·서 모서리 리턴 유지.
   - 남서 옥상 서측 파라펫 10개 캔틸레버 보 천창 격자 + 서측 갤러리 유리 난간 + 남동 지붕 태양광 어레이 2군 유지.
