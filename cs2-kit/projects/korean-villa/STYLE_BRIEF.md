# 신탄진형 다세대·다가구 빌라 스타일 브리프 (`korean-villa`)

- **대상 게임 구역**: Cities: Skylines II 중밀도 주거 구역 (Medium Density Residential)
- **목표 시대·지역**: 2000~2010년대 대전광역시 대덕구 신탄진 생활권(신탄진동·석봉동·덕암동·목상동) 골목의 3~5층 다세대·다가구 빌라 (원룸·투룸형 및 1층 근린상가 복합형 포함)
- **사진 근거**: 네이버 거리뷰 수집 **24동 120장**(`work/roadview_extra/v01_*.png`~`v24_*.png`, `contact_01.png`~`contact_04.png`, 상세 출처 `work/roadview_extra/SOURCES.md`) + 사용자 기준 사진 2장(`user_ref_alley_piloti_villas.png`, `user_ref_alley_charcoal_villa.png`)
- **적용 규범**: `reports/korean_housing_lessons.md` 재발 방지 규칙 25항 전 항목 준수. 거리뷰에서 직접 계측할 수 없는 수치(옥상 내부, 후면 깊이 등)는 `# estimated`로 표기한다.

### 3.3 `korean_housing_lessons.md` D항(17~18항) 비교 결론

1. **벽돌 채도 억제 (17항 검증)**: 과거 폐기된 모델에서 "쨍하다"는 지적을 받은 적갈 벽돌 `(151, 79, 57)`은 채도 `S=0.623`으로 기준(`0.55`)을 크게 초과했다. 반면 신탄진 실측 적갈 벽돌은 **줄눈 포함 평균 S=0.25**, **줄눈을 뺀 순수 벽돌 면조차 `v01` S=0.278·`v07` S=0.349**에 불과하다. 따라서 2단계 생성기의 모든 벽돌 BaseColor는 **채도 `S ≤ 0.35`**로 제한한다.
2. **흰 미장·흰 창틀 명도 클램프 (17항 검증)**: 직사광 아래 흰 미장(`v23_det_bay.png`, V=236)과 흰 PVC 창틀(`v22_det_window.png`, V=240)은 사진상 225를 넘지만, PBR BaseColor에 그대로 쓰면 엔진 태양광이 곱해져 하얗게 날아가고 `albedo_check.py` 경고가 뜬다. 흰 미장·PVC·줄눈 BaseColor는 모두 **최대 채널 `≤ 215` (V ≤ 215)**로 클램프한다.
3. **개방음영 청천반사 보정**: 10월 맑은 하늘 아래 그늘진 차콜 타일(`v06`, `v15`, `user_ref_alley_charcoal_villa.png`)과 흑화강석 기단은 푸른 하늘빛 반사로 B 채널이 R보다 30~80 높게 찍힌다. 텍스처 BaseColor에 파란색을 넣으면 햇빛 아래서 파랗게 뜨므로 반드시 **중성 무채색(S ≤ 0.08)**으로 보정한다.
4. **밝은 회색 시멘트 줄눈 (18항 검증)**: 5개 벽돌 근접 사진의 줄눈 평균은 `[215, 200, 202]`, 채도 `S=0.08`의 밝은 회색 시멘트다. 18항 규칙대로 베이지 줄눈은 금지하고 밝은 회색 시멘트(`(194, 192, 192)`)를 사용한다.

- [ ] **1. 스타일 목표**: 1970~90년대 단독주택풍(기와·적벽돌 담장·오래된 문주)을 배제하고, 2000~2010년대 신탄진 골목의 3~5층 필로티/상가형 다세대 빌라로 한정한다.
- [ ] **2. 사진 기준 필수**: 모든 치수·색·부재 배치는 본 `STYLE_BRIEF.md` 및 `work/roadview_extra/v01~v24` 근거 파일명을 `shape_notes.md`에 연결하고, 미관측 추정값(옥상 바닥·물탱크·깊이 등)은 `# estimated`로 표기한다.
- [ ] **3. 근접 검토 필수**: 4방향 원거리 렌더만으로 통과시키지 않고, 사람 눈높이(`1.6 m`)·거리 `3~6 m` 근접 렌더(`tools/render.py --zoom` 사용, `--box` 금지)를 필로티 기둥·현관/우편함·창+방범난간·모서리 기단·옥상 파라펫 끝단에서 촬영해 로드뷰 근접 사진과 나란히 대조한다.

### B. 형상 (메시)
- [ ] **4. 겹침 면(z-fighting) 0**: `check.py` `COPLANAR = 0` 필수. 필로티 기둥↔충돌방지 띠, 기단↔상부 벽, 난간 세로살↔가로대, 창틀↔벽면, 옥상 갓돌 모서리, 실외기 거치대↔벽, 간판↔파사드 모두 맞대기(abut) 또는 `2~5 mm` 오프셋 적용.
- [ ] **5. 지면 아래·지면 접촉 밑면 금지**: `z < 0` 정점 금지. 필로티 기둥·현관 코어·1층 기단·담장 등 `z = 0`에 닿는 모든 박스는 `skip=("bottom",)` 적용.
- [ ] **6. `z = 0` 바닥 포장 메시 금지**: 필로티 주차장 아스팔트·콘크리트 바닥이나 주차선 메시를 `z = 0`에 깔지 않는다(에디터 Surface로 처리). 주차 구획 표현이 필요하면 카스토퍼(3D 블록)와 기둥 충돌방지 띠만 배치.
- [ ] **7. 계단 틈 금지·막힌 난간벽**: 외부 계단 옵션(`v14` 유형) 사용 시 디딤판 두께 > 단 높이(또는 경사 밑판)로 틈을 메우고 벽에 밀착시키며, 철골 살 난간 대신 **막힌 콘크리트 난간벽 + 갓돌**로 만든다.
- [ ] **8. 띠·갓돌·처마·기단 모서리 감싸기**: 1층 화강석 기단, 필로티 상부 슬래브 처마 띠, 옥상 파라펫 갓돌은 모두 3D 솔리드로 모서리를 감싸 끊김 없게 만든다. 현관문·상가 유리문·필로티 진입 구간은 기단 띠를 비워 문 하부를 가리지 않는다.
- [ ] **9. 열린 틈 금지**: 돌출 창대, 미니 캐노피(`v21`), 필로티 처마, 물끊기 턱의 윗면·아랫면·옆면을 모두 닫힌 솔리드로 맞추고 본체 끝면과 정렬해 구멍이 보이지 않게 한다.
- [ ] **10. 면 방향 (행렬식 +1)**: 좌·우 대칭 발코니·창·계단실 배치 시 축 반사(`scale -1`)를 쓰지 않고 회전(`det = +1`)과 좌표 오프셋만 사용해 법선 뒤집힘을 원천 차단한다.
- [ ] **11. 돌출부 옆면·밑면 폐쇄**: 확장 발코니(`v16`, `v20`, `v23`)·돌출창·돌출 계단실(`v24`)의 측면 벽과 하부 소핏(soffit)을 빠짐없이 막아 뒤 벽이 비치지 않게 한다.

### C. 텍스처·UV
- [ ] **12. 글자·표지판 `uv_full()` 사용**: 1층 상가 가로/세로 간판, 건물명 사인(가상명), 남색 건물번호판, 기둥 충돌방지 사선 띠는 `K.paint()` 단색 칸이 아닌 `atlas.uv_full()` 또는 `kitext.uv_cell()`로 판 비율에 정확히 맞춰 매핑한다.
- [ ] **13. 큰 벽면 타일 재질**: 1 m를 초과하는 적갈/고동/차콜 벽돌, 흰/베이지 미장, 화강석/대형 석재 타일은 `tile=(2.4, 2.4)` 등 실제 물리 치수(벽돌 1줄 75 mm 기준 32줄 = 2.4 m) 타일 재질로 적용한다.
- [ ] **14. 긴 띠 분할 매핑**: 필로티 처마 띠, 파라펫 띠, 층간 몰딩처럼 긴 수평 부재는 128 px 칸을 통째로 늘이지 않고 약 `1.2 m` 구간으로 나누어 변형을 번갈아 매핑한다.
- [ ] **15. 오염 띠 금지**: 벽 하단, 발코니 밑면, 파라펫 아래 어두운 오염 띠를 넣지 않는다. 필요 시 창대와 실외기 거치대 아래에만 아주 짧은 저밀도 빗물/황갈색 녹물 자국(핏빛 금지)을 선택 적용한다.
- [ ] **16. 알파 컷아웃 최소화**: 방범 난간, 발코니 난간, 계단실 창살, 실외기 팬 그릴 등은 알파 컷아웃 평면이 아니라 실제 3D 메시 또는 불투명 텍스처로 구현한다.

### D. 색
- [ ] **17. 채도·명도 과다 금지 (`albedo_check.py` 경고 0)**: 본 브리프 3.1절 권장 PBR BaseColor를 사용해 모든 건축 벽면·창틀의 `V ≤ 220`, `S ≤ 0.35`를 유지한다. 상가 간판·남색 번호판처럼 의도적으로 채도가 높은 소형 요소만 근거를 기록한다.
